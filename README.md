# Casino
Online Casino API (FastAPI)
Проект представляет собой бэкенд-часть онлайн-казино, реализованную на Python с использованием FastAPI. API поддерживает различные игровые режимы, аутентификацию пользователей и взаимодействие с базой данных.

📌 Основные возможности
🎰 Игровые автоматы (слоты)

🚀 Игра "Ракета" (аналог крипто-игры)

♠️ Блэкджек (21 очко)

🔐 Система регистрации и аутентификации

💾 Хранение данных в SQLite (с возможностью масштабирования)

⚙️ Зависимости проекта

🚀 Запуск проекта
Установите зависимости:

bash
pip install -r requirements.txt
Запустите сервер:

bash
start.bat
или вручную:

bash
uvicorn main:app --reload
Откройте в браузере:

http://127.0.0.1:8000
Документация API доступна по адресу:

http://127.0.0.1:8000/docs

🔒 Настройки окружения
Создайте файл .env в корне проекта со следующими параметрами:

ini
DATABASE_URL=sqlite+aiosqlite:///./casino.db
JWT_SECRET_KEY=ваш_секретный_ключ
JWT_ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30
📊 База данных
Проект использует SQLite с асинхронным драйвером aiosqlite. При первом запуске автоматически создается файл базы данных casino.db.

Для миграций можно использовать Alembic (опционально):

bash
alembic revision --autogenerate -m "init"
alembic upgrade head
